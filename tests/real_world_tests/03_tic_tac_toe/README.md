# Tic Tac Toe Challenge (TUI)
**Status:** In Progress
**Language:** Cortex (.ctx)

## Goal
Build a TUI-based Tic Tac Toe game in Cortex using raw ANSI escape codes for styling.

## Requirements
- Use `\e` for ANSI escapes.
- Use `read_line()` for user input.
- Secure by default (Permission system will prompt for I/O if used).
- Full game logic in Cortex.
