# Challenge Name: Core I/O & Data Parsing
**Status:** Completed
**Language:** Nox (.nx)

## Goal
Build a script that performs the following "General Purpose" tasks:
1. **File Interaction**: Create, Read, and Write to a .txt or .csv file.
2. **CLI Arguments**: Program should take command line inputs.
3. **String Manipulation**: Read file content and parse it (uppercase conversion, word count).
4. **Error Handling**: Handle missing files gracefully.

## Success Criteria
- Independent (Native Node.js backend).
- Fast execution.
- No memory leaks.
