# Tic Tac Toe Challenge (TUI)
**Status:** Completed
**Language:** Nox (.nx)

## Goal
Build a TUI-based Tic Tac Toe game in Nox using raw ANSI escape codes for styling.

## Requirements
- Use `\e` for ANSI escapes.
- Use `read_line()` for user input.
- Secure by default (Permission system will prompt for I/O if used).
- Full game logic in Nox.
