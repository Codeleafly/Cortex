# Cortex AI Agents Configuration

Cortex is a high-performance, general-purpose programming language built from scratch in TypeScript, designed to be developed and managed by AI agents.

## Project Context
- **Description:** A hybrid JS/Python syntax language running on a numeric bytecode VM.
- **Package Manager:** npm (using workspaces).
- **Primary Commands:** 
  - `npm run build` (Builds all workspaces using `tsc -b`).
  - `npm run test` (Runs all tests via Vitest).
  - `cortex` (Starts the interactive Ink REPL).
